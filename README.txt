JAVA OOP LAB SHEET 07 — VS CODE SOURCE FILES
============================================

This project contains separate folders for all 30 questions from Lab Sheet-07:
1) Exception Handling: Q01-Q10
2) Packages: Q01-Q10
3) Multithreading: Q01-Q10

HOW TO RUN IN VS CODE
1. Extract this ZIP file.
2. Open the extracted Java_OOP_LabSheet07_VSCode folder in VS Code.
3. Install a JDK (Java 17 or newer recommended) and the "Extension Pack for Java".
4. Open the required question folder and open its .java file.
5. Click Run above the main() method, or use the VS Code Run button.
6. For Scanner-based questions, enter the requested input in the Terminal.

IMPORTANT
- Every question has its own folder; don't combine all files into one Java file.
- For package questions, keep the folder structure exactly as provided.
- Q01-Q10 under Packages may have more than one .java file because packages require supporting classes.
- Thread output order may vary between runs; that is normal.
- For Q08 unsafe counter, the actual count is nondeterministic and may sometimes equal 200000 despite the race condition.
